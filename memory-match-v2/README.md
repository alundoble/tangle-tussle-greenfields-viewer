# Memory Match themed battlefield viewer

Static, read-only panorama from actual Godot 4.7.2 Memory Match review scene, exported 28 October 2026.
Contains rendered public preview only, NOT the private Tangle Tussle source.
Touch pinch/drag, Fit Map, Find Pip and character markers. Terrain is native Godot destructible artwork; background is the exact Memory Match source image, composited with terrain and water.
